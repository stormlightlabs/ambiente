# Playable examples

Each example below uses the production `ambiente-wasm` document runtime and
`@ambiente/audio` browser scheduler from Studio. The controls are smaller than
Studio, but the examples do not have a separate music engine.

Browser audio starts only after you select a play button.

## Phrase

A Phrase keeps notes with exact onset and duration. This example creates the
material through Rust document operations, connects it to a voice, and queries
its events through WASM.

A Matrix is canonical `StepPattern` material. Its active cells become Rust
