# Interactive documentation

A guide can include a working control without building a second version of Ambiente. Sätteri compiles MDX with Solid's JSX runtime, so examples use the same components as the application.

## Shared application code

Playable guides use the same application facade, WASM package, and audio runtime as Studio. A guide can show fewer controls, but composition and pattern behavior remain in Rust.
