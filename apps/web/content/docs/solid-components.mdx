Guides can include focused controls without creating a second musical implementation. Sätteri compiles this MDX page with Solid's JSX runtime.

## Shared application code

Playable guides will call the same application facade, WASM package, and audio runtime as Studio. A guide may expose fewer controls, but composition and pattern behavior remain in Rust.
